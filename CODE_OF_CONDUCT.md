# Code of Conduct

UI Forager is maintained as a useful, welcoming reference for people with different backgrounds, abilities, experience levels, and working conditions.

## Expected Behavior

- Be respectful, patient, and specific.
- Assume good intent while staying open to impact.
- Explain disagreement through evidence, tradeoffs, and the needs of the people using the work.
- Call out accessibility, licensing, privacy, and representation concerns constructively.
- Make room for contributors who are new to the project or the technology.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, intimidation, unwanted sexual attention, doxxing, deliberate disruption, and publishing private information without permission are not acceptable.

## Enforcement

Project maintainers may edit, reject, or remove contributions that do not meet these standards and may restrict participation when behavior is harmful. Report a concern privately through the repository owner's GitHub profile contact options rather than posting sensitive details publicly.

This code of conduct is intentionally short. It should make participation safer without pretending that a document replaces thoughtful moderation.
