# Contributing

UI Forager is a curated directory, not a list of every UI library on the internet. Contributions are welcome when they make source selection more reliable, more inclusive, or more useful for a real project.

## Add a Library or Resource

Include:

- The exact official URL and, when possible, the current documentation or source URL.
- What it is best for and what it is not good for.
- Supported frameworks, styling assumptions, and ownership model.
- Package or runtime dependencies and meaningful bundle or performance concerns.
- License, attribution, free/pro split, or marketplace terms.
- Accessibility behavior, known gaps, and the fallback a project should provide.
- One practical reason to choose it over an obvious alternative.

Avoid duplicate entries, unsourced claims, placeholder URLs, and entries added only because they are popular. A smaller curated list is more useful than a larger noisy one.

## Add a 21st.dev Component

Add it to `references/21st-dev.md` using the existing entry format: name, category, stack, dependencies, summary, notes, and full source. Do not add a component without recording its setup requirements and known gotchas.

## Review Checklist

- [ ] The source URL is real and the entry is in the right category.
- [ ] The description says when to use it and when not to use it.
- [ ] License, free/pro status, dependencies, and runtime loading are clear.
- [ ] Accessibility and responsive behavior were checked or marked unknown.
- [ ] Demo logos, customer claims, and brand assets are not presented as generally reusable.
- [ ] The change keeps the directory easy to scan and does not repeat existing guidance.

## Pull Requests

Keep a pull request focused. Explain the decision it improves and include the source links needed for review. Documentation-only changes are welcome; a running demo is helpful but not required.

Please use respectful, specific language. Questions about a source are part of review, not a judgment about the contributor.
